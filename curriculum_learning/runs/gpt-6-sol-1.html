Protocol and constraints

Policy: Qwen3.5-0.8B, fixed BALROG text prompt and sampler. A training target is admitted only from the policy's own valid action or from a counterfactual action tried at a state reached by that policy, with a game response proving the desired effect. Scripted CPU tests are kept outside training data. Plain full-game training time is tracked separately.

I use short sequential supervised blocks with branch-verified lesson targets. This differs from the suggested continuously running PPO loop because the supplied PPO probe learned output format but stalled at stationary play, whereas the first counterfactual SFT block moved the full-game score by 5.68 points. The GPU trains throughout each block; fresh model games and CPU replay mining run during or between blocks. Each block starts from the last scored checkpoint, and the official 100-world result decides whether to keep it.
